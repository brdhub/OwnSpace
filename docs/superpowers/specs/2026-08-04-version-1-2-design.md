# OwnSpace v1.2 版本调整设计

## 目标

将 OwnSpace 当前展示版本与 npm 包版本统一调整为 v1.2，并将本轮秋招企业功能写入历史更新日志后推送到当前 `master` 分支。

## 设计

- `src/config/app-version.ts` 的首条发布记录改为 `1.2`，更新日期为 `2026-08-04`。
- v1.2 日志记录秋招企业只读同步、筛选、收藏生成计划和投递表单预填。
- 原 v2.1 与 v2.0 记录继续保留在历史更新日志中。
- `package.json` 与 `package-lock.json` 的项目版本统一改为 `1.2.0`。
- 不修改数据库结构、用户数据或业务流程。

## 验证

- 更新版本历史测试，确认 v1.2 位于首位且历史记录保留。
- 运行完整测试、类型检查、Lint 和生产构建。
- 提交后推送当前 `master` 到 `origin`。
