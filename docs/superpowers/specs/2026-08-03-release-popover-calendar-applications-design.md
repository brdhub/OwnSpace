# 2.1 更新日志收起与日历投递标记设计

## 目标

- 历史更新日志展开后，点击弹窗和版本按钮以外的任意位置即可收起。
- 首页日历按投递日期展示当天是否投递，并在选中日期后显示投递数量。
- 完成后将本补丁写入 v2.1 更新日志。

## 更新日志交互

- Sidebar 使用一个同时包含版本按钮与日志弹窗的容器引用。
- 弹窗打开时监听文档级 `pointerdown`；事件目标位于容器之外时关闭弹窗，容器内部点击不关闭。
- 同时监听 `Escape` 键关闭弹窗，保持键盘可用性。
- 弹窗关闭时移除监听器，避免长期驻留事件处理器。

## 日历数据

- `CalendarActivityDay` 增加 `applicationCount: number`。
- `getCalendarActivityDays()` 在现有日记和学习查询基础上读取投递记录的 `appliedDate`。
- 同一日期的投递记录按条数累加；没有投递的日期按 0 处理。
- 把活动日聚合逻辑提取为纯函数，以便在不读写真实 SQLite 数据的情况下测试。

## 日历界面

- 日期格底部状态条由两列扩展为三列：日记为橙色、投递为蓝色、学习为绿色深浅。
- 图例新增蓝色“投递”。
- 日期按钮的无障碍描述增加“投递 N 份”。
- 选中日期后显示“已投递 N 份”；没有投递时显示“未投递”。
- 面试仍使用右上角红色标记，不改变现有面试详情交互。

## 不在本次范围

- 不改变投递记录的创建和编辑流程。
