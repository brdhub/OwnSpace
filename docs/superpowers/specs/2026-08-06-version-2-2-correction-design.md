# OwnSpace v2.2 版本纠正设计

## 目标

纠正错误发布的 v1.2 版本号，将当前应用展示版本统一为 v2.2、npm 包版本统一为 2.2.0，并以新增提交推送，不改写远端历史。

## 设计

- 将 `appReleases` 首条记录从 `1.2` 改为 `2.2`，日期更新为 `2026-08-06`。
- 保留该记录中的秋招企业同步、筛选、收藏和投递预填说明。
- 历史更新日志仅保留正确的 `2.2`、`2.1`、`2.0`，不继续展示错误的 `1.2`。
- 将 `package.json` 与 `package-lock.json` 的根项目版本改为 `2.2.0`。
- 不修改业务逻辑、数据库结构或用户数据。

## 验证与交付

- 先更新版本契约测试并确认旧实现失败，再修改版本元数据使测试通过。
- 运行完整测试、类型检查、Lint、生产构建和 Git 差异检查。
- 创建新的纠正提交并正常推送 `master`，不使用强推。
