# OwnSpace v1.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将当前应用与 npm 包版本统一调整为 v1.2，记录秋招企业功能并推送。

**Architecture:** 沿用现有 `appReleases` 单一版本展示源，并同步 npm 清单版本。只修改版本元数据和对应测试，不触及业务状态或数据库。

**Tech Stack:** TypeScript、Node.js、Next.js、Node test runner、Git

## Global Constraints

- 当前展示版本必须为 `1.2`。
- npm 包版本必须为 `1.2.0`。
- v2.1 与 v2.0 必须继续保留在历史更新日志中。
- 更新日期固定为 `2026-08-04`。
