# 可恢复简历优化实施计划

用户已批准推荐方案与解析错误处理设计。基于现有未提交 v3.4 改动增量实现，保持当前目录，不合并、推送或发布。

## 设计与边界

- LangGraph SQLite 检查点存入 data/langgraph-checkpoints.db；业务运行、调用预算和输出仍由 ownspace.db 管理。
- 每次优化对应独立 thread_id/runId；恢复前校验输入版本、工作流版本与运行占用。模型调用前持久化预算，最多两次请求，恢复不重置预算。
- 图按 prepare → 可选 awaitFacts → generate → validate → repair/finish 分支执行。修正只处理失败条目，耗尽后原文回退并明确原因。
- 单条补充重写是新的显式运行，先持久化等待，再由 interrupt/Command 恢复；不改正式条目库，不覆盖其他条目的审阅状态。
- 执行结果与业务表提交分离且幂等，检查点不承诺外部调用恰好一次。无后台任务或云追踪。
- PDF 读取错误与模型整理错误分开；结构化提取增加一次错误指导修正，保留原候选直到成功。不新增 OCR 或全流程解析图。
