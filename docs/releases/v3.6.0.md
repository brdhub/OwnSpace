# OwnSpace v3.6.0

发布日期：2026-09-23

## 更新摘要

- 投递记录新增城市、岗位类型和所用简历；支持相应筛选、同公司记录折叠和缺失类型匹配。
- 新建投递默认选择深圳和最近上传的简历，提交前可调整。
- 投递导出新增数量趋势、进度和招聘类型统计图，可按日期范围下载统计图片；明细导出保留。
- 调整投递页操作按钮布局，清理过时调研文档和生成缓存。

单张明细图片最多导出 100 条记录；较大范围可先按日期或页面条件筛选。统计图片不受这一限制。

## 升级

升级前备份 `data` 与 `.env.local`。源码安装执行 `npm ci`、`npm run db:migrate`、`npm run build`。迁移 0022–0023 为投递记录增加可空字段及简历关联索引，不删除已有数据。
