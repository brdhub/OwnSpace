# OwnSpace v3.7.0

发布日期：2026-09-24

## 更新摘要

- 优化首页：投递统计移至首页，以更清晰的数量、趋势和招聘类型切换展示进展；移除推荐投递区。
- 优化投递记录 UI：筛选和投递网址改为按需展开，新增投递按钮居中；编辑框、保存与删除操作重新排布。
- 增加投递轨迹：状态变化自动留痕，支持按日期补录过去的状态，并可从投递卡片查看详情。
- 完善 AI 面试：根据投递 JD 和选定简历生成五题文字模拟，每题最多一次追问；回答、反馈和复盘保存在本地，可中断续答。
- 秋招企业移至简历模块；原地址会保留筛选参数跳转。

## 升级

升级器会先备份用户数据，再应用数据库迁移并构建新版本。源码安装请先备份 `data` 与 `.env.local`，随后执行 `npm ci`、`npm run db:migrate` 和 `npm run build`。本版新增迁移 `0024_mute_stryfe.sql`（投递状态轨迹）与 `0025_interview_simulator.sql`（模拟面试会话），不会清空已有投递记录。

文字模拟面试仅在用户点击开始、提交回答或重试评估后调用本机配置的 DeepSeek；JD、所选简历文本和本次回答会发送给模型。AI 反馈仅供练习，不代表真实面试结果。
