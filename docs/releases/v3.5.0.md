# OwnSpace v3.5.0

发布日期：2026-09-12

本次发布整合 v3.3 之后尚未发布的工作区改动，完善从简历素材到岗位简历制作、保存和导出的流程。

## 新增与改进

- **简历制作**：目标岗位保存后即可手动选材、编辑基本信息、调整分区顺序及条目显隐、预览并保存不可变版本；支持 DOCX 下载和打印为 PDF。JD 与 AI 推荐、优化均为可选步骤。
- **可恢复优化**：使用本地 LangGraph 与 SQLite 检查点；支持手动继续中断流程、一次失败条目定向修正，以及用户补充事实后重写。恢复不会重置调用预算，失败项保留原文。
- **PDF 条目提取**：逐条校验并保留合格候选，仅对失败项修正一次；部分成功显示具体原因，修正失败不会丢失本次已合格结果。
- **条目补充**：利用现有提取请求判断与正式条目的关联，本地比较字段；默认补齐空字段、合并技术栈与标签、保留冲突旧值。用户确认后更新原条目，保存前后快照与原文依据，支持撤回和过期编辑保护。判断及合并不增加模型请求。
- **经历结构**：区分项目内容与个人职责；同一实习支持多个所属项目，详情复制与文档生成同步支持这些字段。
- **长经历兼容**：提高文档正文容量，避免合法的多项目实习条目在生成草稿时因合并后的正文长度被拒绝。

## 升级

在线升级：重新启动 `start-ownspace.cmd`，确认升级至 v3.5.0。

离线升级：下载 `OwnSpace-v3.5.0-offline-updater.zip`，解压并运行“升级 OwnSpace.cmd”，选择已有应用目录。升级器会备份并迁移本地数据。

源码安装：先备份 `data` 和 `.env.local`，再执行 `npm ci`、`npm run db:migrate`、`npm run build`。

新增迁移 0019–0021 涵盖简历草稿/版本、工作流运行状态和条目补充快照。保留原有 SQLite 数据与附件，不提交或打包个人数据库、本机配置、密钥及构建缓存。

## 范围说明

- PDF 提取正常一次、最多两次模型请求；此次条件分支不提供提取过程的持久化恢复。持久化恢复用于简历优化。
- PDF OCR 尚未提供；没有可用文字的 PDF 仍需手动处理。
- 关联与补充需要用户核对，系统不自动判定冲突事实的真伪。条目补充后再次修改时，禁止直接撤回以免覆盖后续内容。
- 未进行真实 DeepSeek 调用与延迟测量；模型行为通过可控响应和错误场景测试验证。
